# اتصال حساب شخصی OpenRouter در وارنیکس

## رفتار کاربر
1. کاربر در وارنیکس وارد تنظیمات و بخش «اتصال حساب شخصی OpenRouter» می‌شود.
2. دکمه اتصال، صفحه رسمی `https://openrouter.ai/auth` را با OAuth PKCE باز می‌کند.
3. کاربر در OpenRouter وارد حسابش می‌شود یا حساب جدید می‌سازد؛ اگر گزینه ورود با Google در صفحه نمایش داده شود، می‌تواند آن را انتخاب کند.
4. OpenRouter پس از تأیید، کاربر را به deep link زیر برمی‌گرداند:
   `com.varnix.ai://login-callback`
5. برنامه کد را با code_verifier به `/api/v1/auth/keys` مبادله می‌کند و کلید API شخصی کاربر را دریافت می‌کند.

## امنیت و صورتحساب
- وارنیکس رمز Google یا OpenRouter را دریافت نمی‌کند.
- OAuth از PKCE با SHA-256 استفاده می‌کند؛ verifier به‌صورت موقت در Android Secure Storage نگهداری می‌شود.
- کلید API در Android Secure Storage و با شناسه حساب وارنیکس همان کاربر ذخیره می‌شود؛ در جدول‌های Supabase ذخیره نمی‌شود.
- هنگام ارسال پیام، کلید از طریق HTTPS به تابع احرازشده `chat` فرستاده و برای همان درخواست به OpenRouter منتقل می‌شود.
- هزینه درخواست‌ها از اعتبار حساب شخصی OpenRouter کاربر کم می‌شود.
- با قطع اتصال، کلید ذخیره‌شده محلی پاک می‌شود.
- اتصال برای هر حساب وارنیکس و هر دستگاه جداگانه انجام می‌شود.

## انتشار
پس از تغییر تابع چت، گردش‌کار GitHub Actions با نام **Deploy Varnix chat function** را اجرا کنید. این گردش‌کار به GitHub Secret با نام `SUPABASE_ACCESS_TOKEN` نیاز دارد.
سپس APK امضاشده را از گردش‌کار **Build Varnix AI Signed APK** بسازید.
