# Varnix AI 2.0

دستیار هوش مصنوعی فارسی‌زبان برای اندروید، متصل به زیرساخت مرکزی Supabase.

## قابلیت‌ها
- ثبت‌نام و ورود با ایمیل و رمز عبور
- دریافت تنظیمات عمومی برنامه از دیتابیس، بدون نیاز به انتشار APK برای هر تغییر
- ارسال گفتگو از طریق Edge Function احراز هویت‌شده
- استفاده از مدل‌ها و کلیدهای API مدیریت‌شده توسط مالک
- کلیدهای ارائه‌دهندگان در Supabase Vault نگهداری می‌شوند و به اپ کاربر برگردانده نمی‌شوند
- تاریخچه گفتگو و پشتیبان‌گیری محلی
- لینک کانال روبیکا و مایکت قابل مدیریت از پنل مالک

## پنل مالک
مخزن جداگانه و خصوصی پنل مالک:
`razyoamir-ux/Varnix-Owner-Panel`

پنل وب و نسخه اندروید از همان پروژه Supabase استفاده می‌کنند. ورود فقط برای حسابی مجاز است که نقش `admin` در جدول `profiles` داشته باشد.

## تنظیمات بک‌اند
پروژه Supabase:
- URL: `https://gwhlihrijgpdvcpleodi.supabase.co`
- Edge Function گفتگو: `chat`
- جدول تنظیمات: `app_config`
- رجیستری مدل‌ها: `ai_models`
- کلیدهای ارائه‌دهندگان: `provider_api_keys` با نگهداری امن در Vault

کلید قابل انتشار Supabase در برنامه استفاده می‌شود؛ کلید `service_role` یا کلید ارائه‌دهنده هوش مصنوعی نباید داخل APK یا کد فرانت‌اند قرار بگیرد.

## ساخت APK با GitHub Actions
۱. به تب **Actions** مخزن بروید.
۲. گردش‌کار **Build Varnix AI APK** را انتخاب کنید.
۳. پس از موفقیت، فایل `varnix-ai-apk` را از بخش Artifacts دانلود کنید.

### ساخت محلی
```bash
flutter pub get
flutter analyze
flutter build apk --release
```

## نکات راه‌اندازی
- کاربران باید با حساب خود وارد شوند؛ برای ثبت‌نام، تأیید ایمیل ممکن است لازم باشد.
- مالک باید از پنل مالک حداقل یک کلید API فعال برای ارائه‌دهنده مدل ثبت کند.
- تنظیمات عمومی در شروع برنامه از سرور دریافت می‌شوند و از منوی برنامه نیز می‌توان آن‌ها را دستی تازه‌سازی کرد.
- تغییرات دیتابیس بدون APK جدید اعمال می‌شوند؛ تغییرات خود کد یا رابط کاربری همچنان به انتشار نسخه جدید نیاز دارند.
