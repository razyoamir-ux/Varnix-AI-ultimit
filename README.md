# Varnix AI 2.0

دستیار هوش مصنوعی فارسی‌زبان سبک و زیبا برای اندروید.

## ویژگی‌ها

- رابط کاربری مدرن تیره با تم بنفش و آبی
- اتصال واقعی به OpenRouter (مدل رایگان پیش‌فرض)
- پنل مالک با رمز عبور (پیش‌فرض: `246810`)
- ذخیره امن API Key
- تاریخچه چت، پشتیبان‌گیری و بازیابی
- لینک کانال روبیکا، پرداخت و مایکت قابل تنظیم
- کاملاً راست‌چین و فارسی

## ساخت APK با GitHub Actions (پیشنهادی – بدون نیاز به کامپیوتر)

۱. یک مخزن جدید در GitHub بسازید.
۲. تمام فایل‌های این پروژه را آپلود کنید (یا با Git push کنید).
۳. به تب **Actions** بروید.
۴. workflow به نام **Build APK** را انتخاب کنید.
۵. روی **Run workflow** کلیک کنید.
۶. پس از اتمام ساخت (حدود ۵–۱۰ دقیقه)، فایل APK را از بخش Artifacts دانلود کنید.

### ساخت APK محلی (اگر Flutter نصب دارید)

```bash
flutter pub get
flutter build apk --release
```

فایل APK در مسیر زیر قرار می‌گیرد:

```
build/app/outputs/flutter-apk/app-release.apk
```

## تنظیمات اولیه

پس از نصب برنامه:

1. از منوی سه‌نقطه وارد **پنل مالک** شوید.
2. رمز پیش‌فرض: `246810`
3. کلید API خود را از [OpenRouter](https://openrouter.ai) بگیرید و وارد کنید.
4. مدل، شخصیت، لینک‌ها و سایر تنظیمات را تغییر دهید.
5. رمز پنل را حتماً عوض کنید.

## نکات امنیتی

- کلید API با `flutter_secure_storage` در حافظه امن اندروید ذخیره می‌شود.
- رمز پنل مالک نیز به صورت امن نگهداری می‌شود.
- هیچ کلید درگاه پرداخت داخل برنامه قرار نگرفته است. پرداخت فقط از طریق لینک خارجی انجام می‌شود.
